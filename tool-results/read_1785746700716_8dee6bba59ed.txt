    28→## Fixes Applied
    29→
    30→### Fix D1: CORS Origin Allowlist
    31→**Before**: Reflected any non-null origin; fell back to `*` for null/absent origins.
    32→**After**: Added `ALLOWED_ORIGIN_RE` allowlist with patterns for:
    33→- `localhost:*` and `127.0.0.1:*` (development)
    34→- `preview-chat-[hex]-*.space-z.ai` (preview proxy)
    35→- Placeholder for production domains
    36→
    37→Only allowlisted origins are reflected with `Access-Control-Allow-Credentials: true`. Unknown or null origins get no `Access-Control-Allow-Origin` header (browser enforces same-origin policy). This closes the origin-reflection attack vector while ensuring the preview proxy works correctly.
    38→
    39→### Fix D2: Bot-Blocked Debug Headers
    40→**Before**: 403 response only had `x-response-time`.
    41→**After**: Added two headers:
    42→- `x-bot-blocked: true` — boolean flag for quick identification
    43→- `x-bot-match: <regex-source>` — identifies which pattern matched (e.g. `^curl\/`), or `empty-ua` for missing User-Agent
    44→
    45→Log line also enhanced: `403 bot-blocked [^curl/] 2ms` for easier grep.
    46→
    47→### Fix D3: Rate Limiter Size Cap
    48→**Before**: Lazy cleanup every 200 checks only.
    49→**After**:
    50→- Extracted `evictExpired(now)` helper function
    51→- Added `RL_MAX_ENTRIES = 10_000` constant
    52→- Cleanup now triggers when `rlStore.size > RL_MAX_ENTRIES` in addition to the 200-check interval
    53→- Prevents memory pressure under burst traffic with many unique IPs
    54→
    55→### Fix D4: Matcher Static Extensions
    56→**Before**: `jpe?g` was missing (only `jpg`), plus `gif`, `webp`, `avif`, `webmanifest`.
    57→**After**: Updated extension list: `svg|png|jpe?g|gif|webp|avif|ico|css|js|woff2?|ttf|eot|webmanifest`
