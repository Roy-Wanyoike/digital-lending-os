    50→    79→    79→    79→        if hasattr(flowable, 'bookmark_name'):
    51→    80→    80→    80→            level = getattr(flowable, 'bookmark_level', 0)
    52→    81→    81→    81→            text = getattr(flowable, 'bookmark_text', '')
    53→    82→    82→    82→            key = getattr(flowable, 'bookmark_key', '')
    54→    83→    83→    83→            self.notify('TOCEntry', (level, text, self.page, key))
    55→    84→    84→    84→
    56→    85→    85→    85→# 2. MUST add TableOfContents to story
    57→    86→    86→    86→toc = TableOfContents()
    58→    87→    87→    87→toc.levelStyles = [toc_level0, toc_level1]  # define your styles
    59→    88→    88→    88→story.append(toc)
    60→    89→    89→    89→story.append(PageBreak())
    61→    90→    90→    90→
    62→    91→    91→    91→# 3. MUST set bookmark attributes on every heading
    63→    92→    92→    92→def add_heading(text, style, level=0):
    64→    93→    93→    93→    key = f'h_{hashlib.md5(text.encode()).hexdigest()[:8]}'
    65→    94→    94→    94→    p = Paragraph(f'<a name="{key}"/>{text}', style)
    66→    95→    95→    95→    p.bookmark_name = key
    67→    96→    96→    96→    p.bookmark_level = level
    68→    97→    97→    97→    p.bookmark_text = text
    69→    98→    98→    98→    p.bookmark_key = key
    70→    99→    99→    99→    return p
    71→   100→   100→   100→
    72→   101→   101→   101→# 4. MUST use multiBuild (NOT build)
    73→   102→   102→   102→doc = TocDocTemplate(output_path, pagesize=A4, ...)
    74→   103→   103→   103→doc.multiBuild(story)
    75→   104→   104→   104→```

   187→   216→   216→   216→## Step 3: EDIT - Content Transformation
   188→   217→   217→   217→
   189→   218→   218→   218→**Before writing any code, restructure raw text into visual roles.** This is the most impactful quality step - skipping it produces "Word document with a PDF extension".
   190→   219→   219→   219→
   191→   220→   220→   220→### 3a. Typographic Role Extraction
   192→   221→   221→   221→
   193→   222→   222→   222→Parse raw text and categorize content into visual roles:
   194→   223→   223→   223→
   195→   224→   224→   224→| Role | ReportLab Mapping | Description |
   196→   225→   225→   225→|------|------------------|-------------|
   197→   226→   226→   226→| **Hero / Display** | Cover title (36-42pt) or section opener | 1-5 words, the emotional hook |
   198→   227→   227→   227→| **Kicker / Eyebrow** | Subtitle or section intro (10-12pt, muted) | Tiny context line above main heading |
   199→   228→   228→   228→| **Data Sculpture** | CalloutBox or bold stat block | Extract impactful numbers (97%, $4.2M, -45ms) |
   200→   229→   229→   229→| **Pull Quote** | BlockQuote (italic + left indent 24pt + accent border) | Most provocative sentence, standalone |
   201→   230→   230→   230→| **Body** | Standard paragraph | Everything else |
   202→   231→   231→   231→
   203→   232→   232→   232→**Rule**: Before writing any body paragraph, scan for numbers with units. Every metric like "revenue grew by 12%" or "latency dropped to 45ms" MUST be extracted into a CalloutBox or metrics table - never buried in paragraph prose. See §Data-to-Ink Ratio Rules below.
   204→   233→   233→   233→
   205→   234→   234→   234→### 3b. Section Pacing
   206→   235→   235→   235→
   207→   236→   236→   236→- If any H1 section has **>400 words** of continuous body text without visual breaks, split into H2 subsections or insert a visual break (table, chart, callout)
   208→   237→   237→   237→- Aim for at least 1 visual element (table/chart/callout) per 2-3 pages of body text
   209→   238→   238→   238→- Dense text walls are the #1 sign of poor report design
   210→   239→   239→   239→
   211→   240→   240→   240→### 3c. Content Sanitization for External Sources (MANDATORY when source is PDF/OCR/web)
   212→   241→   241→   241→
   213→   242→   242→   242→When content is extracted from an external PDF, OCR output, or web scrape, it may contain invisible garbage characters that cause garbled rendering. **You MUST sanitize the text content before writing it into any `Paragraph()` or `canvas.drawString()`.**
   214→   243→   243→   243→
   215→   244→   244→   244→This is different from `code.sanitize` (which cleans Python source code). Content sanitization cleans the **text data itself**.
   216→   245→   245→   245→
   217→   246→   246→   246→```python
   218→   247→   247→   247→import re
   219→   248→   248→   248→
   220→   249→   249→   249→def content_sanitize(text: str) -> str:
   221→   250→   250→   250→    """Strip invisible/control chars from externally-sourced text."""
   222→   251→   251→   251→    # Remove control chars (except \n \t)
   223→   252→   252→   252→    text = re.sub(r'[\x00-\x08\x0b\x0c\x0e-\x1f\x7f]', '', text)
   224→   253→   253→   253→    # Remove zero-width chars
   225→   254→   254→   254→    text = re.sub(r'[\u200b-\u200f\u2028-\u202f\u2060\ufeff]', '', text)
   226→   255→   255→   255→    # Remove replacement char (upstream encoding error)
   227→   256→   256→   256→    text = text.replace('\ufffd', '')
   228→   257→   257→   257→    # Remove variation selectors
   229→   258→   258→   258→    text = re.sub(r'[\ufe00-\ufe0f]', '', text)
   230→   259→   259→   259→    # Remove private use area chars
   231→   260→   260→   260→    text = re.sub(r'[\ue000-\uf8ff]', '', text)
   232→   261→   261→   261→    return text
   233→   262→   262→   262→```
   234→   263→   263→   263→
   235→   264→   264→   264→**When to use:**
   236→   265→   265→   265→| Source | Must sanitize? |
   237→   266→   266→   266→|--------|---------------|
   238→   267→   267→   267→| User typed text in prompt | No (usually clean) |
   239→   268→   268→   268→| Extracted from PDF via `pdf.py extract.text` | **YES** |
   240→   269→   269→   269→| OCR output | **YES** |
   241→   270→   270→   270→| Web scrape / HTML strip | **YES** |
   242→   271→   271→   271→| LLM-generated content | No (usually clean) |
   243→   272→   272→   272→
   244→   273→   273→   273→⚠️ **Do NOT confuse** `code.sanitize` (Step 6, cleans Python code) with `content_sanitize()` (Step 3, cleans text data). They solve different problems.

   273→   302→   302→   302→## Character Safety Rule (MANDATORY)
   274→   303→   303→   303→
   275→   304→   304→   304→Three rules for safe character handling in ReportLab PDFs:
   276→   305→   305→   305→
   277→   306→   306→   306→**a) Superscripts and subscripts**: Use `<super>`/`<sub>` tags, never raw Unicode superscript/subscript characters (e.g., `\u00b2`, `\u2082`).
   278→   307→   307→   307→
   279→   308→   308→   308→**b) Emoji**: ReportLab cannot render emoji. If content contains emoji, use Creative brief (HTML + Playwright).
   280→   309→   309→   309→
   281→   310→   310→   310→**c) Font fallback for mixed CJK/Latin text (MANDATORY)**: After registering fonts, you **MUST** call `install_font_fallback()` once. This automatically wraps missing-glyph characters in `<font>` tags inside every `Paragraph()`. No manual `<font name="...">` wrapping needed for mixed Chinese-English text. **Skipping this call is the #1 cause of Helvetica garbled text in CJK documents.**
   282→   311→   311→   311→
   283→   312→   312→   312→**d) canvas.drawString / drawRightString CJK font rule (MANDATORY)**: `install_font_fallback()` only works on `Paragraph()` objects. It does NOT affect `canvas.drawString()` / `canvas.drawRightString()` / `canvas.drawCentredString()`. If the text passed to any `canvas.draw*String()` call contains CJK characters (Chinese/Japanese/Korean), you **MUST** call `canvas.setFont('NotoSerifSC', size)` (or another registered CJK font) before drawing. Using FreeSerif / Helvetica / Times for CJK canvas text = garbled output.
   284→   313→   313→   313→
   285→   314→   314→   314→```python
   286→   315→   315→   315→# ❌ WRONG — FreeSerif has no CJK glyphs, '科大讯飞' will be garbled
   287→   316→   316→   316→canvas.setFont('FreeSerif-Italic', 8)
   288→   317→   317→   317→canvas.drawRightString(x, y, 'SZSE: 002230  ·  科大讯飞')
   289→   318→   318→   318→
   290→   319→   319→   319→# ✅ CORRECT — use CJK font for mixed text
   291→   320→   320→   320→canvas.setFont('NotoSerifSC', 8)
   292→   321→   321→   321→canvas.drawRightString(x, y, 'SZSE: 002230  ·  科大讯飞')
   293→   322→   322→   322→
   294→   323→   323→   323→# ✅ ALSO CORRECT — pure English text can use FreeSerif
   295→   324→   324→   324→canvas.setFont('FreeSerif-Italic', 8)
   296→   325→   325→   325→canvas.drawString(x, y, 'Prepared by Strategy Advisory Team')
   297→   326→   326→   326→```
   298→   327→   327→   327→
   299→   328→   328→   328→Mathematical/relational operators (×, ÷, ±, ≤, √, ∑, ≅, ∫, π, ∠, Δ, etc.) are safe to use as literal characters in `Paragraph()` - both Noto Sans SC and FreeSerif have these glyphs.
   300→   329→   329→   329→
   301→   330→   330→   330→| Need | Correct Method | Correct Example |
   302→   331→   331→   331→|------|---------------|---------|
   303→   332→   332→   332→| Superscript | `<super>` tag in `Paragraph()` | `Paragraph('10<super>2</super> × 10<super>3</super> = 10<super>5</super>', style)` |
   304→   333→   333→   333→| Subscript | `<sub>` tag in `Paragraph()` | `Paragraph('H<sub>2</sub>O', style)` |
   305→   334→   334→   334→| Bold | `<b>` tag in `Paragraph()` | `Paragraph('<b>Title</b>', style)` |
   306→   335→   335→   335→| Math operators | Literal char in `Paragraph()` | `Paragraph('AB ⊥ AC, ∠A = 90°, and ΔABC ≅ ΔDCF', style)` |
   307→   336→   336→   336→| Scientific notation | Combined tags in `Paragraph()` | `Paragraph('1.2 × 10<super>8</super> kg/m<super>3</super>', style)` |
   308→   337→   337→   337→
   309→   338→   338→   338→```python
   310→   339→   339→   339→from reportlab.platypus import Paragraph
   311→   340→   340→   340→from reportlab.lib.styles import ParagraphStyle
   312→   341→   341→   341→from reportlab.lib.enums import TA_LEFT, TA_CENTER, TA_JUSTIFY
   313→   342→   342→   342→
   314→   343→   343→   343→body_style = ParagraphStyle(
   315→   344→   344→   344→    name="ENBodyStyle",
   316→   345→   345→   345→    fontName="FreeSerif",
   317→   346→   346→   346→    fontSize=10.5,
   318→   347→   347→   347→    leading=18,
   319→   348→   348→   348→    alignment=TA_JUSTIFY,
   320→   349→   349→   349→)
   321→   350→   350→   350→
   322→   351→   351→   351→# CJK Body (Chinese documents)
   323→   352→   352→   352→cn_body_style = ParagraphStyle(
   324→   353→   353→   353→    name="CNBodyStyle",
   325→   354→   354→   354→    fontName="NotoSerifSC", fontSize=10.5, leading=18,
   326→   355→   355→   355→    alignment=TA_LEFT,      # ← NEVER TA_JUSTIFY for CJK
   327→   356→   356→   356→    wordWrap='CJK',         # ← MANDATORY for CJK
   328→   357→   357→   357→    firstLineIndent=2*4.5*mm,
   329→   358→   358→   358→)
   330→   359→   359→   359→
   331→   360→   360→   360→# Superscript: area unit
   332→   361→   361→   361→Paragraph('Total area: 500 m<super>2</super>', body_style)
   333→   362→   362→   362→
   334→   363→   363→   363→# Subscript: chemical formula
   335→   364→   364→   364→Paragraph('The reaction produces CO<sub>2</sub> and H<sub>2</sub>O', body_style)
   336→   365→   365→   365→
   337→   366→   366→   366→# Scientific notation
   338→   367→   367→   367→Paragraph('Speed of light: 3.0 × 10<super>8</super> m/s', body_style)
   339→   368→   368→   368→
   340→   369→   369→   369→# Combined
   341→   370→   370→   370→Paragraph('E<sub>k</sub> = mv<super>2</super>/2', body_style)
